# NOVA

NOVA is a single-page digital product studio landing page built with React and Vite.

## Included

- Editorial hero with responsive art direction
- Capabilities, selected work, About and Insights sections
- Scroll reveal, active-section navigation, animated metrics and project carousel
- Accessible contact modal with local success state
- Responsive layout and reduced-motion support

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

Live preview: https://nova-modern-studio.vercel.app/
